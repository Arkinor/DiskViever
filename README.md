# DiskViever — умный визуализатор дисков

Интерактивное desktop-приложение для визуального анализа занятого места на дисках
и умной очистки мусора. Показывает структуру каталогов в виде круговой диаграммы,
позволяет «проваливаться» вглубь дерева папок и находить самые тяжёлые файлы,
а на отдельной вкладке — находить и безопасно удалять системный мусор и остатки
удалённых программ.

Стек: **Python 3.11**, **Tkinter** (UI), **Matplotlib** (рендер диаграммы),
**psutil** (данные о дисках), **send2trash** (удаление в корзину).

> **Весь код в этом репозитории полностью сгенерирован нейросетью** — от структуры
> проекта и нейминга функций до комментариев и этого README. Репозиторий ведётся
> как эксперимент «что умеет AI-ассистент».

## Возможности

### Вкладка «📊 Визуализатор»

- **Обзор дисков** — при запуске сканируются все подключённые разделы и их занятое место.
- **Круговая диаграмма** с выносом подписей за пределы круга; подписи автоматически
  раскладываются по вертикали, чтобы не перекрывать друг друга.
- **Два режима отображения** (кнопка `↔ Вид` или средняя кнопка мыши):
  - `Диаграмма` — секторы, пропорциональные размеру;
  - `Проводник` — вертикальный список строк с полосами-индикаторами.
- **Навигация по дереву каталогов**: вход в папку, возврат на уровень назад, «домой».
- **Hover-подсветка** — выбранный элемент остаётся ярким, остальные затемняются.
- **Поиск по имени** и **сортировка** по размеру/имени.
- **Экспорт в CSV** текущего среза данных.
- **Индикатор сканирования** — спиннер, прогресс-бар и текст «что именно считается»
  прямо в статус-баре, поэтому больше не непонятно, что происходит при входе в диск.
- **Автообновление** — раз в 4 секунды проверяется, не изменился ли текущий каталог;
  при изменениях данные пересчитываются автоматически. Кнопка `↻ Обновить` / `F5`
  пересчитывает вручную и сбрасывает кэш.
- **Инвалидация кэша** — при входе в каталог и при возврате назад размеры пересчитываются
  заново, поэтому удалённые/добавленные файлы сразу видны.

### Вкладка «🧹 Умная очистка»

Аналог базового функционала CCleaner, ориентированный на системный диск Windows.

- **Поиск системного мусора** по декларативным правилам:
  - временные файлы (`%TEMP%`, `C:\Windows\Temp`);
  - кэш Windows Update и Delivery Optimization;
  - Prefetch, кэш миниатюр/иконок, кэш шейдеров DirectX/NVIDIA/AMD/Intel;
  - отчёты об ошибках (WER), дампы падений, логи Windows;
  - кэш браузеров (Chrome, Edge, Brave, Яндекс, Opera, Firefox);
  - кэш приложений (Discord, Slack, Teams, Spotify);
  - кэш разработчика (pip, npm, NuGet), кэш шейдеров Steam;
  - старые установщики в «Загрузках» (старше 45 дней);
  - корзина.
- **Поиск остатков удалённых программ** — сверяет папки в `AppData\Local`,
  `AppData\Roaming`, `LocalLow`, `ProgramData`, «Документах» и «Сохранениях игр»
  с установленными программами. Установленные программы собираются из:
  - реестра Uninstall (HKLM, WOW6432Node, HKCU);
  - Steam (все библиотеки из `libraryfolders.vdf`);
  - Epic Games Store (манифесты);
  - GOG (реестр);
  - ярлыков меню «Пуск»;
  - каталогов `Program Files`, `Games`, `SteamLibrary`, `Epic Games`, `GOG Games`
    **на всех локальных дисках**.
- **Уровни риска** у каждого элемента:
  - 🟢 `Безопасно` — можно удалять без последствий;
  - 🟡 `Осторожно` — проверьте содержимое (например, остатки программ);
  - 🔴 `Опасно` — только для информации, удаление вручную системными средствами.
- **Группировка по категориям**, суммарные размеры, фильтр по имени/пути.
- **Выборочное удаление** галочками, кнопка «Безопасное» отмечает всё безопасное.
- **Удаление в корзину** по умолчанию (через `send2trash`, с fallback на WinAPI
  `SHFileOperation`). Безвозвратное удаление — только при снятой галочке «В корзину»
  и после подтверждения.
- **Отчёт CSV** со всеми найденными элементами.
- **Подробности** по каждому элементу: описание, путь, риск, примечание.

## Управление

### Визуализатор

| Действие | Клавиша / кнопка |
| --- | --- |
| Войти в каталог | ЛКМ по сектору или строке |
| Назад на уровень | кнопка `← Назад` или ПКМ |
| Вернуться к списку дисков | кнопка `🏠 Домой` или `Esc` |
| Сменить режим (диаграмма/проводник) | кнопка `↔ Вид` или СКМ (колесо) |
| Поиск по имени | поле в верхней панели, очистка — `✕` |
| Сортировка размера/имени | кнопка `↕ Сортировка` |
| Обновить данные | кнопка `↻ Обновить` или `F5` |
| Автообновление | галочка в нижней панели |
| Сохранить отчёт | кнопка `💾 Экспорт` |

### Умная очистка

| Действие | Элемент |
| --- | --- |
| Начать анализ | кнопка `🔍 Анализ` |
| Остановить анализ | кнопка `🛑 Стоп` |
| Выбрать/снять элемент | клик по `☐/☑` или `Space` |
| Выбрать всё безопасное | кнопка `☑ Безопасное` |
| Снять весь выбор | кнопка `☐ Снять выбор` |
| Удалить выбранное | кнопка `🗑 Удалить` |
| Открыть папку элемента | двойной клик, `📂 Открыть` или кнопка в подробностях |
| Скопировать путь | ПКМ → «Копировать путь» или `📋 Путь` |
| Фильтр по имени/пути/категории | поле `🔎` в панели действий |
| Экспорт отчёта | кнопка `💾 Отчёт CSV` |

## Требования

- Python **3.11**.
- Установленный Tcl/Tk (входит в стандартные сборки Python на Windows и macOS;
  на Linux — пакет `python3-tk`).
- Зависимости из `requirements.txt`: `matplotlib`, `psutil`, `send2trash`.
  `tkinter` в список не входит — он часть стандартной библиотеки.

> Приложение использует шрифты `Segoe UI` и `Consolas`, поэтому лучше всего выглядит
> на Windows. Функции очистки Windows-специфичны; на Linux/macOS доступен базовый
> набор правил, а поиск остатков программ отключается.

## Установка

```bash
git clone https://github.com/<username>/DiskViever.git
cd DiskViever

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Окно открывается развёрнутым; минимальный размер — `1000x700`.

### Как это устроено

| Блок | Назначение |
| --- | --- |
| `DiskVisualizer(tk.Tk)` | Главное окно: `ttk.Notebook` с вкладками «Визуализатор» и «Умная очистка». |
| `ui_kit` | Кнопки с hover/нажатием, карточки статистики, единые стили ttk. |
| `start_busy` / `stop_busy` / `_spin` | Спиннер и прогресс-бар в статус-баре, текст текущей операции. |
| `_start_directory_scan` | Фоновое сканирование каталога с прогрессом и инвалидацией кэша. |
| `_auto_refresh_tick` | Периодическая проверка `mtime` текущего каталога. |
| `SmartCleanerTab` | Вкладка очистки: таблица категорий, риски, выбор, удаление, отчёт. |
| `Scanner.scan` | Проход по правилам + поиск остатков программ, возвращает `ScanResult`. |
| `find_orphans` | Сопоставление папок с установленными программами, фильтры размера/возраста. |
| `delete_items` | Удаление выбранного, журнал в `~/.diskvieuver/cleanup_log.jsonl`. |

## Журнал очистки

Все операции удаления пишутся в `~/.diskvieuver/cleanup_log.jsonl`:
время, путь, размер, правило и способ удаления (корзина/безвозвратно).

## Известные ограничения

- **Права доступа.** Каталоги без прав на чтение молча пропускаются — их размер
  в статистику не попадёт. Часть системных правил требует запуска от администратора.
- Раздел `Размер` считается по фактическим размерам файлов, а не по месту на диске
  (cluster slack и жёсткие ссылки не учитываются).
- Симлинки не разыменовываются, чтобы не зациклиться на циклических ссылках.
- Поиск остатков программ эвристический: возможны ложные срабатывания, поэтому
  такие элементы помечены `Осторожно` и не выбираются автоматически.
- `Windows.old`, `WinSxS\Backup`, `C:\Windows\Installer`, `pagefile.sys`,
  `hiberfil.sys` показываются только для информации — удалять их вручную нельзя.
