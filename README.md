# Disk Visualizer

Интерактивное desktop-приложение для визуального анализа свободного и занятого места на дисках.
Показывает структуру каталогов в виде круговой диаграммы, позволяет «проваливаться» вглубь дерева
папок и находить самые тяжёлые файлы и директории.

Стек: **Python 3.11**, **Tkinter** (UI), **Matplotlib** (рендер диаграммы), **psutil** (сбор данных о дисках).

> **Весь код в этом репозитории полностью сгенерирован нейросетью** — от структуры проекта и
> нейминга функций до комментариев и этого README. Репозиторий ведётся как эксперимент
> «что умеет AI-ассистент»: ни одной строки, написанной руками.

## Возможности

- **Обзор дисков** — при запуске сканируются все подключённые разделы и их занятое место.
- **Круговая диаграмма** с выносом подписей за пределы круга: подписи автоматически раскладываются
  по вертикали, чтобы не перекрывать друг друга.
- **Два режима отображения** (переключение средней кнопкой мыши):
  - `Диаграмма` — секторы, пропорциональные размеру;
  - `Проводник` — вертикальный список строк с полосами-индикаторами.
- **Навигация по дереву каталогов**: вход в папку, возврат на уровень назад, мгновенный переход «домой».
- **Hover-подсветка** — при наведении курсора выбранный элемент остаётся ярким, остальные затемняются.
- **Поиск по имени** в текущей директории с мгновенной перерисовкой.
- **Сортировка** по размеру (по умолчанию) или по имени.
- **Экспорт в CSV** текущего среза данных (кодировка `utf-8-sig`, разделитель `;` — открывается в Excel без танцев с бубном).
- **Фоновое сканирование** — обход файловой системы выполняется в отдельном потоке, интерфейс не подвисает.
- **Кэш размеров каталогов** — повторные обходы одной и той же папки не выполняются.
- **Защита от мелких секторов** — сегменты меньше `2.2°` получают минимальный угол, чтобы по ним можно было кликнуть.
- **Анимация появления** диаграммы при смене директории и **пересчёт макета при ресайзе** окна.

## Управление

| Действие | Клавиша / кнопка |
| --- | --- |
| Войти в каталог | ЛКМ по сектору или строке |
| Назад на уровень | ПКМ |
| Сменить режим (диаграмма/проводник) | СКМ (колесо) |
| Вернуться к списку дисков | `Esc` |
| Поиск по имени | поле ввода в верхней панели |
| Сортировка размера/имени | кнопка `↕ Сортировка` |
| Сохранить отчёт | кнопка `💾 Экспорт CSV` |

## Требования

- Python **3.11** — проект разработан и проверен именно на этой версии (в коде используется синтаксис аннотаций `int | float`, доступный с 3.10, но гарантируется работа на 3.11).
- Установленный Tcl/Tk (входит в стандартные сборки Python на Windows и macOS;
  на Linux — пакет `python3-tk`).
- Зависимости из `requirements.txt`: `matplotlib`, `psutil`. `tkinter` в список не входит — он часть стандартной библиотеки и через pip не ставится.

> Приложение использует шрифты `Segoe UI` и `Consolas`, поэтому лучше всего выглядит на Windows.
> На Linux и macOS работает, но шрифты будут заменены на системные.

## Установка

```bash
git clone https://github.com/<username>/DiskViever.git
cd DiskViever

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Окно открывается развёрнутым; минимальный размер — `1000x700`.

## Структура проекта

```text
DiskViever/
├── main.py            # всё приложение: сбор данных, UI, рендер диаграммы, экспорт
├── requirements.txt   # matplotlib, psutil
└── .gitignore
```

### Как устроен `main.py`

| Блок | Назначение |
| --- | --- |
| `get_readable_size` | Перевод байт в человекочитаемый вид (Б, КБ, МБ, ГБ, ТБ, ПБ, ЭБ). |
| `get_color_for_level` / `lighten_color` | Подбор цвета из палитры по глубине вложенности. |
| `get_directory_size` | Итеративный (без рекурсии) обход каталога с записью результата в кэш. |
| `DiskVisualizer(tk.Tk)` | Главное окно: тулбар, холст Matplotlib, статус-бар. |
| `render_chart` / `render_explorer` | Отрисовка двух режимов отображения. |
| `calculate_display_angles` | Распределение углов секторов с минимальным порогом. |
| `on_click` / `on_mouse_move` | Обработка мыши, поиск сектора и hover-подсветка. |
| `navigate_to_item` / `go_back` / `go_home` | Навигация по дереву с историей. |
| `export_to_csv` | Сохранение текущего среза в CSV. |

## Экспорт CSV

Файл содержит текущий (с учётом поиска) список элементов:

| Имя | Размер (байт) | Размер (формат) | Тип |
| --- | --- | --- | --- |
| `Windows` | `128849018880` | `120.0 ГБ` | Каталог |

Имя файла формируется автоматически: `disk_report_ГГГГММДД_ЧЧМСС.csv`.

## Известные ограничения

- **Права доступа.** Каталоги без прав на чтение молча пропускаются — их размер в статистику не попадёт.
- Раздел `Размер` считается по фактическим размерам файлов, а не по месту, занятому на диске
  (cluster slack и жёсткие ссылки не учитываются).
- Симлинки не разыменовываются, чтобы не зациклиться на циклических ссылках.

## Сборка в exe (опционально)

В `.gitignore` уже исключены артефакты PyInstaller, поэтому приложение можно собрать в один файл:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name DiskVisualizer main.py
```
